# HealthMate Android Project

Purple HealthMate Android starter project.

Included:
- Custom purple mobile UI
- Home nutrition dashboard
- Food photo selection/camera workflow
- Nutrition estimate screen
- Manual meal logging
- Calories, protein, carbs, fat
- Meal history and local storage
- Barcode workflow placeholder
- Profile/settings

Important: photo results in this starter are clearly marked as sample estimates. A real AI vision model and live barcode/product database need an external service/database connection.

Build:
Open the folder in Android Studio, let Gradle sync, then Build > Build APK(s).
